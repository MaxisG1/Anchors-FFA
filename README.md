⚓ Anchors FFA

A fast-paced Free-For-All (FFA) combat addon for Minecraft Bedrock Edition, built using the Script API. Anchors FFA delivers competitive PvP gameplay with custom kits, interactive menus, shops, and progression systems designed for multiplayer servers.

⚔️ Core Features
🧠 High-performance FFA gameplay system
🧰 Custom kit selection system
🛒 Fully interactive shop UI system
💎 Custom enchantment system
🧱 Block-based interactive menus (click-to-use)
🎁 Crates & reward systems
🏆 Boss fights & PvE loot events
🎣 Fishing & farming expansion areas
🛡️ Anti-spam cooldown protection
⚡ Optimized Script API event handling

⚙️ Performance Design:
Anchors FFA is built for smooth multiplayer performance:
🚀 Constant-time block lookup (no world scanning)
🧩 Event-driven architecture
⏱️ Player cooldown system (prevents spam)
🧠 Minimal overhead interaction handling
